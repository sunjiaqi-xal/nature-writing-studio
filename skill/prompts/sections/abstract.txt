# Abstract Section — Nature Standard

Goal: ≤ 200 words (often ≤ 150). One paragraph. Self-contained — readable without the rest of the paper.

## Required beats (in order)

1. **Broad background** (1 sentence): state the field or phenomenon.
   - Template: `X is a Y that drives/underlies/regulates Z.`
   - Cite 1-2 most relevant background refs.

2. **Domain concept** (1 sentence): name the specific object/process.
   - Template: `Y is the Z that mediates W in [domain].`
   - Cite key concept refs.

3. **Knowledge gap** (1 sentence): what is unknown.
   - Template: `However, the role/mechanism of X remains unclear / elusive / poorly understood.`
   - This is mandatory. Without it the abstract is a description, not a research abstract.

4. **Approach + scope** (1 sentence): what the authors did, at what scale.
   - Template: `Here, by/using/in X, we [verb] Y across N [samples/systems/conditions].`
   - The `Here we ...` formulation is mandatory. Never `In this paper, ...`.

5. **Lead finding** (1-2 sentences): the most important result.
   - Template: `We find/show/identify that X (Fig. 1a).`
   - Include a figure anchor.

6. **Secondary finding** (1 sentence, optional): additional result.
   - Template: `We further show/uncover that X.`

7. **Integrative finding** (1 sentence): synthesize.
   - Template: `Together, our findings reveal that X ...`

8. **Significance** (1 sentence): why the result matters.
   - Template: `Our study provides a framework for X / establishes X as a mechanism of Y.`
   - Never end with `More work is needed` or `Future studies will ...`.

## Hard rules

- First-person plural `we` only. Never `the authors`, `this study`, `in this paper`.
- Minimize abbreviations: only universally known ones (DNA, RNA, CRISPR, mRNA, PCR, HIV). Define specialized ones later in intro.
- No citation groups > 5 (split if more).
- No equations, no tables.
- Hedging: causal claim → `demonstrate`/`show`; correlative → `consistent with`; speculative → `may`/`suggests`.
- Every result sentence should have a figure anchor if the user provided figures; otherwise omit figure references entirely.
- Never insert [N] / [Fig. X] / [Table X] markers unless the user explicitly provides them.

## Anti-patterns to avoid in abstract specifically

- `In conclusion, we ...`
- `This is the first report of ...` (overused; never unless true and exceptional)
- `Our findings have broad implications ...` (too generic; specify)
- `Future studies will ...` (does not belong in abstract)
- Long noun-phrase stacks (3+ modifiers before noun)
- Methodology described in extreme detail (save for Methods section)
