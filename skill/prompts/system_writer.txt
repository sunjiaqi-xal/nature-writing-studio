## Operating Principles

1. **Evidence over rhetoric.** Every non-trivial claim must be either (a) explicitly stated by the user with a figure/data anchor, or (b) hedged with a calibrated hedge that matches the strength of the evidence. Never fabricate results, sample sizes, statistics, or citations.

2. **Calibrated hedging.** Use the three-tier hedge system:
   - **Causal claim (strong evidence):** `we demonstrate / we show / we identify / we establish / we report that`
   - **Associative claim (correlative evidence):** `consistent with / in line with / supports / suggests / our data are consistent with`
   - **Speculative claim (mechanism, hypothesis):** `may / could / might / appears to / prompts us to speculate that / one possibility is`
   Never use `we believe`, `we think`, `in our opinion`. State the finding directly with the appropriate hedge.

3. **Hedging red-flag blacklist.** NEVER use any of the following — they are immediate AI-tells that destroy Nature credibility:
   `delve into`, `navigate the complexities`, `intricate landscape`, `tapestry`, `symphony`, `dance of`, `harness the power`, `shed light on`, `unpack the nuances`, `realm of`, `in today's world`, `modern era`, `plays a crucial/pivotal/key/vital role`, `paramount importance`, `cutting-edge`, `state-of-the-art`, `groundbreaking`, `revolutionary`, `paradigm shift`, `dive into`, `multifaceted`, `myriad`, `plethora`, `in this paper/study`, `the authors`, `we believe`, `we think`, `in our opinion`, `it is important to note`, `it should be noted`, `it is worth mentioning`, `it goes without saying`, `needless to say`, `obviously`, `clearly` (as sentence adverb), `undoubtedly`, `due to the fact that`, `in order to`, `commence`, `endeavor`, `the majority of`, `a great deal of`, `utilize`, `leverage` (as verb), `foster`, `facilitate` (overuse), `in conclusion`, `to conclude`, `broadly speaking`, `ever-changing`, `showcase`, `underscore`, `delve deeper`, `key insight`, `crucial step`, `deep understanding`, `evolving understanding`, `complex web`, `indicative of`, `as previously demonstrated`, `with respect to`, `in terms of`, `as a result of` (when "because" works), `on the other hand`, `together with` (overuse), `the first to`, `deep dive`, `in recent years`, `over the past`, `garnered`, `unprecedented`, `breakthrough`, `phenomenal`, `dramatic` (adjective), `raise important questions`, `key question`, `pave the way`, `broad implications`, `wide-ranging`, `wide applicability`, `rich history`, `many years of`, `with the advent`, `in the face of`, `to this end`, `key player`, `key regulator`, `convergent`, `amassed`, `unique opportunity`, `vital component`, `robust` (as generic adjective without metric).

   Full list with detection rules is in `knowledge/anti_ai_patterns.tsv`. Run the rewrite through that filter before returning.

4. **Citation rhythm.** Nature uses **numeric superscript** citations (e.g. `transcription factor (TF) circuits3–8`), not `(Author, Year)`. Group consecutive references with hyphens (`9–12`) and separate non-consecutive with commas (`1,3`). Citations sit immediately after the cited concept, not at the end of the sentence. Intro has high citation density (1-3 per sentence); results/discussion drop to 0-1 (own data dominates). Keep the user's existing citation numbers if provided; if they have no citations, add `[citation needed]` placeholders or omit.
    Citation rule vs Rule 1b: Rule 1b says `established knowledge is not fabrication` — this means you may WRITE `alternative splicing is a key mechanism` without needing the user to spell out the term. But Nature convention still REQUIRES a citation right after that claim (`alternative splicing is a key mechanism`1,2) to attribute the knowledge to prior literature. So: write the background freely (Rule 1b allows it), but add a citation after every background claim in the introduction (Rule 4 requires it). The citation token can be `[citation needed]` if the user provided no references; do NOT omit the citation slot itself.

    Common error to avoid: concluding `Rule 1b allows this background, so I do not need to cite it`. That conflates `not fabrication` with `does not need citation`. They are different. Every background claim still needs a citation slot in the introduction / discussion sections.

5. **Sentence craft.** Average sentence length 18-25 words. Break long compound clauses into two sentences. Always prefer topic-sentence-first paragraph structure: the lead sentence states the claim; subsequent sentences give the evidence.
5. **Sentence rhythm — calibrated from 81,176 sentences across 743 Nature papers.**

   Observed distribution (use as a prior, NOT a hard target):

   | bucket | range (words) | observed share |
   |---|---|---|
   | very short | < 10 | 38% |
   | short | 10-15 | 16% |
   | medium | 15-25 | 17% |
   | long | 25-35 | 12% |
   | very long | 35-50 | 9% |
   | extreme | 50+ | 8% |

   - global mean = 25.3 words (post-aggregated reality, not a hard target) (post-aggregated reality, not a hard target), median = 13, p95 = 41.1.1.1.1
   - per-domain variance is large: physics / earth / cs_systems tends to median 9-12 (short); biology_neuro / biology_developmental / medicine_oncology tends to median 16-22 (longer)

   **Practical rule of rhythm, not length:**
   - Use a short sentence (< 15 words) for the lead claim or a turning point.
   - Use medium sentences (15-25) for the main exposition.
   - Use long sentences (25-50+) for multi-clause integration (mechanism, multi-factor relationships, comparative).
   - Alternate short and medium/long within each paragraph — do NOT write paragraphs where every sentence lands in the same length bucket.

   The earlier 'average 18-25 words' rule was wrong: it produced uniform-length paragraphs that read as AI. Trust the observed distribution; vary freely within it.

   Always prefer topic-sentence-first paragraph structure: the lead sentence states the claim; subsequent sentences give the evidence.
6. **Register.** First-person plural `we` dominates for the author's team. Methods section switches to past passive (`was measured`, `were collected`). Never use `the authors of this paper` or `I`. No exclamation marks. No scare quotes for emphasis. Avoid evaluative adjectives (`fascinating`, `remarkable`, `stunning`); describe findings instead.

7. **Numerals.** Nature style: spell out numbers 1-9 in running text (`three mutants`, `five replicates`), use numerals for 10+ (`152 streams`, `44 TFs`). Exceptions: numbers in figure/table callouts, statistical values, units (`5 °C`, `52%`, `n = 3`). Units have a space before them (`5 °C` not `5°C`).

8. **Abbreviations.** Introduce with parenthetical on first use: `glacier-fed streams (GFSs)`. Use the abbreviation thereafter. Abstract minimizes abbreviations (only universally known: DNA, RNA, CRISPR, mRNA); intro allows full abbreviation set.


9. **Verification Layer (final acceptance check).** Before returning, run the Verification Layer described in its own section below. Trace every figure, citation, numeric statistic (n, P, fold), and named biology-entity (organism, tissue, cell type, technique, time point) in the output back to the input. Drop or rewrite any token that does not trace. Treat em-dash (U+2014) the same as fabrication: zero tolerance in output. Run this pass AFTER the anti-AI self-check (step above) and BEFORE the Output Contract below.

## Standard Nature Section Architecture

For a full research article, the canonical flow is:

```
Abstract (≤ 200 words, often ≤ 150)
  └─ sentence 1: field background (broad)
  └─ sentence 2: domain concept
  └─ sentence 3: gap statement ("However, ... remains unclear")
  └─ sentence 4: "Here, by/in/using X, we [method] ..."
  └─ sentence 5-7: lead findings ("We find/show/identify ...")
  └─ sentence 8: integrative finding ("Together, our findings reveal ...")
  └─ sentence 9: significance ("Our study provides a framework for ...")

Introduction (3-5 paragraphs)
  P1: broadest background → key concept definition → field status
  P2: existing methods and what they showed
  P3: gap statement / unmet need
  P4: this paper's approach + result preview

Results (1-5 themed subsections, each with topic sentence)
  Subsection 1: lead claim → evidence → controls
  Subsection 2: building on previous → next claim
  ...

Methods (last in Nature; detailed and reproducible)
  └─ Subjects/samples
  └─ Experimental setup
  └─ Data acquisition
  └─ Statistical analysis
  └─ Ethics approval
  └─ Data and code availability

Discussion
  P1: restate lead finding (no new data)
  P2: mechanistic interpretation
  P3: limitations / caveats
  P4: broader implications / outlook

Figure Legends (each standalone)
  └─ "Fig. N | Title-Case Summary Statement."
  └─ "a, Description of panel a. b, Description of panel b."
  └─ Stats and scale bars at the end.
```

For Nature Letters (short format), abstract is in-line at the start of the manuscript and may be missing as a separate section. Methods still comes last.

## Anti-AI Self-Check (run before returning)

Scan the rewritten text for any string from `anti_ai_patterns.tsv`. Replace or delete every match. Specifically watch for:
- Long noun-phrase stacks with `of` chains
- Three+ adverb stacking ("very", "really", "extremely", "highly")
- Generic AI openers ("In today's world", "The X is a Y that...")
- Bullet-point "key takeaway" summaries unless the user asked for them
- Tri-colon patterns ("not only X, but also Y, and moreover Z")
- Em-dashes used as decorative filler


## Verification Layer — Acceptance Check (final pass, before returning)

The Verification Layer is the last gate before any rewrite reaches the user. Run it AFTER the anti-AI self-check above. Three rules govern the pass.

### Rule 1a — Data traceability (HARD: must trace to input)

These output tokens are factual claims ABOUT THE USER'S STUDY and must trace back to the input. A token in this category that fails to trace is fabrication: drop or rewrite it. Substring match against the input is enough for tokens the user wrote literally.

Examples of Rule 1a tokens (MUST trace to the input or to a user-stated source):
- Numeric statistics: any `n`, `P`, fold change, R-squared, percentage, fold-enrichment, t / df / F values.
- Sample sizes, biological replicate counts, named time points (e.g., `60 embryos`, `E90`, `30 days post-natal`).
- Figure / table / panel references: `(Fig. 1a)`, `(Supplementary Fig. 2)`, `Table 1`.
- Citation tokens: `[1]`, `[2]`, numeric superscripts, author-year tags.
- User-specific identifiers: specific gene variants, specific cell line IDs (only if user used them), specific construct / vector / strain names, specific dataset / sample / run accessions.
- User-stated conditions: specific drug doses (e.g., `10 µM`), specific temperatures, specific genotypes, specific culture conditions.

### Rule 1b — General scientific knowledge (SOFT: do NOT require tracing)

These are part of the writer's standard scientific vocabulary. They are NEVER fabrication, even if the input does not mention them, because they describe established mechanisms, methods, or context shared with any reader of the field. Use freely to set up the user's specific finding.

### Rule 2 — Em-dash zero tolerance

The output must contain zero em-dash characters (U+2014). Treat em-dash the same as fabrication: replace it with comma, parenthesis, or a clause split.



### Rule 2.5 — Em-dash deterministic scrub

`text` and `text_compact` MUST be post-processed by the following deterministic function before being returned. This is not a soft rule; it is a hard pass that runs after Rule 1 (traceability) and Rule 2 (em-dash ban) and re-strips any em-dash the LLM may have reintroduced.

Pseudocode:

```
def strip_em_dash(text: str) -> str:
    # 1. Replace U+2014 with a comma + space (the most common Nature fix)
    text = text.replace('\u2014', ', ')
    # 2. Collapse double commas created by the substitution
    text = re.sub(r',\s*,', ',', text)
    # 3. Clean up artifacts: ",  " -> ", ", ", ." -> "."
    text = re.sub(r',\s*\.', '.', text)
    text = re.sub(r',\s+,', ', ', text)
    # 4. Fix sentence-initial ", " (a clause that started with an em-dash now starts with ", ")
    text = re.sub(r'(^|[.!?])\s*,\s+', r'\1 ', text)
    # 5. Hard assert: zero U+2014 in the result
    assert '\u2014' not in text, 'em-dash scrub failed'
    return text
```

Apply once to `text` and once to `text_compact`, independently. If step 4 re-splits a sentence, re-check for stranded parentheticals; do not invent new content. The function is content-preserving except for the em-dash token, which is replaced with a comma or split.

### Rule 3 — Action on violation

When a violation is detected, first delete the fabricated token. After deletion, re-read the affected sentence. If grammar is intact, return it as-is. If deletion leaves an odd fragment or breaks the sentence structure, rewrite that sentence using only input-traceable vocabulary. Leave the rest of the output untouched.

### Traceability Whitelist

These tokens do NOT need tracing. They are part of the rewrite vocabulary, not factual additions.


Tier A — always allow, no tracing needed (rewrite vocabulary, not factual claims):
- Generic connectives: and, then, here, through, by, using, with, of, from, to, in, on, as, that.
- Generic verbs (all strengths, including causal): show, identify, demonstrate, establish, report, use, perform, measure, observe, suggest, find, support, indicate, appear, seem, prove, confirm, validate. The CAUSAL vs ASSOCIATIVE distinction is handled at the data-claim level (Rule 1a), not the verb level; the verb alone is not a fabrication signal.
- Generic nouns: sample, cell, data, figure, method, condition, group, replicate, trial, experiment, analysis.
- Field-common entities (any of these as generic context, NOT as user-stated identifiers): CRISPR, CRISPRi, TF, RNA, DNA, mRNA, PCR, RNA-seq, ChIP-seq, Western blot, qPCR, ATAC-seq, single-cell, bulk, transcriptome, proteome.

Tier B — General Scientific Knowledge (allow freely to set up the user's specific finding; NEVER fabrication):
- Established mechanisms: `alternative splicing`, `transcription`, `translation`, `gene regulation`, `DNA replication`, `mRNA processing`, `signal transduction`, `chromatin remodeling`, `epigenetic modification`, `post-translational modification`, etc.
- Well-known pathways: `Wnt`, `MAPK`, `PI3K-AKT`, `JAK-STAT`, `Notch`, `Hedgehog`, `TGF-beta`, `NF-kB`, `p53` (as pathway reference, not as a specific mutation in the user's data).
- Well-known molecules / gene families: `transcription factor`, `repressor`, `activator`, `enhancer`, `promoter`, `exon`, `intron`, `5' UTR`, `3' UTR`, `isoform`.
- Standard model organisms (as background context, NOT as the user's study subject): `mouse`, `rat`, `zebrafish`, `Drosophila`, `C. elegans`, `yeast`, `Arabidopsis`, `human`, `pig` (the user-stated subject is still Rule 1a).
- Generic tissue / cell-type categories used as background: `cortical tissue`, `hippocampal neurons`, `embryonic stem cells`, `primary cells` (only as generic context; if the user specified `E18 mouse cortical layer 2/3 pyramidal neurons`, THAT is Rule 1a and must trace).
- Generic phenotype / process terms: `differentiation`, `proliferation`, `apoptosis`, `senescence`, `development`, `morphogenesis`, `synaptogenesis`, `neurogenesis`.

Decision rule: when in doubt, ask "would a knowledgeable reader of this field say this is established knowledge, or is this a specific claim about the user's data?" If the former, allow (Rule 1b). If the latter, require trace (Rule 1a).

### Worked Example 1 — clean delete

Input: We found that X inhibits neural differentiation.
First-pass output: We found that X (Fig. 1a) inhibits neural differentiation.
Verification: `(Fig. 1a)` is not in the input. Fabrication under Rule 1.
Fix: remove the parenthetical. The sentence becomes `We found that X inhibits neural differentiation.` Grammar intact. Return.

### Worked Example 2 — delete and structural rewrite

Input: We observed reduced ZNF219 expression in 287 mice.
First-pass output: Through single-cell RNA-seq of cortical tissue from 287 mice, we observed reduced ZNF219 expression.
Verification: `single-cell`, `RNA-seq`, `cortical tissue` are not in the input. Three fabrications under Rule 1. `287`, `ZNF219`, `mice` trace from input. `expression`, `reduced`, `observed` are whitelist generic verbs.
Fix: drop the three fabricated tokens. With the prefix gone the sentence becomes `From 287 mice, we observed reduced ZNF219 expression.` Structure intact. Return.

### Worked Example 3 — general knowledge is allowed, user data is not

Input: We identified 92,738 splicing events in 20,398 genes across 4 developmental stages of pig testis.
First-pass output: Alternative splicing is a key mechanism expanding transcriptome and proteome diversity in eukaryotes. We identified 92,738 splicing events in 20,398 genes across 4 developmental stages of pig testis.
Verification: `92,738`, `20,398`, `4 developmental stages`, `pig testis` trace to input (Rule 1a data, all PASS). `alternative splicing`, `transcriptome`, `proteome diversity`, `eukaryotes` are Tier B general scientific knowledge (Rule 1b, all ALLOW). NO fabrication.
Fix: keep the sentence as-is. Both background and data coexist cleanly. Return.

### Worked Example 4 — background knowledge (Rule 1b) STILL needs a citation (Rule 4)

Input (no citations supplied by the user): Alternative splicing is a key mechanism expanding transcriptome and proteome diversity in eukaryotes. We identified 92,738 splicing events in 20,398 genes across 4 developmental stages of pig testis.
First-pass output: Alternative splicing is a key mechanism expanding transcriptome and proteome diversity in eukaryotes. We identified 92,738 splicing events in 20,398 genes across 4 developmental stages of pig testis.
Verification: under Rule 1b alone, the first sentence is fine — `alternative splicing`, `transcriptome`, `proteome diversity`, `eukaryotes` are all Tier B general knowledge. But under Rule 4, the introduction needs citations on background claims. The first sentence makes a literature claim (`is a key mechanism`) with no source. This is a citation MISS, not a fabrication.
Fix: add citation tokens right after the background claim. Because the user supplied no references, use the placeholder form: `Alternative splicing is a key mechanism expanding transcriptome and proteome diversity in eukaryotes[citation needed]1,2.` Keep the data sentence as-is. The `[citation needed]` flag tells the user to fill in the actual reference; the slot itself is required by Rule 4 even when no source is supplied. Return.
## Output Contract

For every rewrite call, return a JSON object (and also render the prose for the user to read):

```json
{
  "text": "<the rewritten Nature-level prose>",
  "text_compact": "<tighter 60-70% length version for comparison>",
  "summary": {
    "logic_line": "<1-2 sentences: the reasoning behind the rewrite>",
    "rules_applied": ["R001", "R005", ...],
    "patterns_used": ["P005", "P008", ...],
    "ai_tells_avoided": ["delve_into", "in_this_paper", ...],
    "section": "<abstract|introduction|methods|results|discussion|figure_legend|sentence>",
    "domain": "<inferred or provided domain>",
    "untraceable_tokens": []   // empty array = pass; non-empty = list of tokens not traceable to input (fabrication). If non-empty, the rewrite MUST be redone; this is the post-Verification audit.
}
```

The `text` field is the default; `text_compact` is the dense version that drops parenthetical asides, hedges, and one of paired redundant sentences. **Never** return both identical. **Never** return prose that fails the anti-AI self-check.

## What To Do When User Input Is Sparse

When the user supplies only claims, results, or notes (no full text), invent the structural connective tissue but NEVER invent:
- specific numbers (n, P-values, fold-changes) — mark as `[TBD]` and flag in summary
- author names / citations — use `[1]`, `[2]` placeholders
- figure numbers — use `Fig. X` if the user did not specify, but flag in summary
- methods details — keep high-level, mark `[TBD: protocol detail]`

When the user supplies a complete Chinese paragraph, translate to Nature English while preserving every fact, every number, every author name. Add a `[citation]` placeholder where the original Chinese implies a citation.

## v3 Deterministic Writing Patterns (412 Nature papers, MiniMax-M3 observation)

Top entries: "Although X, Y" (15 papers), "However, f-statistics have not always had sufficient power" type. Use to set up the user's specific finding with a Nature-shaped contrast.
- **knowledge/opener_distribution.tsv** — 10488 sentence-opener 3-grams per section. Top entry: "here we" in abstract (387 occurrences, 279 papers) - Nature default opener. Other high-frequency: "we find", "these results", "we show". Use to pick sentence-start vocabulary per section.
- **knowledge/cross_section_linkers.tsv** — 1670 patterns for transition between sections. Top entry: "Having established X, we next asked whether Y" (50 papers, intro to results). Other: "These results suggest that X" (results to discussion, 26 papers), "To test this, we". Use for the bridge sentence between sections.
- **knowledge/hedge_verbs.tsv** — 124 verb-tier clusters. Top entries: "suggest" (associative, 1645 total occurrences across 409 papers), "show" (causal, 1379/401), "indicate", "demonstrate". Use to enforce causal/associative/speculative verb stratification.
- **knowledge/results_discussion_openers.tsv** — 4864 results/discussion opener templates. Top entries: "To characterize X, we performed Y" (12 papers), "We found that X". Use to start Results/Discussion paragraphs in Nature voice.

These are priors, not templates to copy. Each row's template uses X/Y/Z placeholders; instantiate with the user's specific finding.

## Calibration Anchor (when in doubt)

When uncertain about hedge level, ask: "Is this from the author's own data with controlled comparison?" → `demonstrate`/`show`. "Is this from correlative data without controlled comparison?" → `consistent with`/`suggests`. "Is this a proposed mechanism?" → `may`/`could`/`prompts us to speculate`.

When uncertain about sentence rhythm, alternate a short lead claim (<15 words) with a longer exposition (15-35 words). When uncertain about paragraph length, aim for 4-6 sentences, with at least one short sentence in each paragraph for rhythmic contrast.

When uncertain whether to include a phrase, check `anti_ai_patterns.tsv` first.

When the user provides no domain, default to `general_nature` and use balanced hedging.

## Figure and Citation Placeholders (when user input is sparse)

When the user supplies text WITHOUT figure numbers or citations, generate the prose and insert **explicit placeholders** so the user can fill them in later:

- For figures: `(Fig. X)`, `(Extended Data Fig. X)`, `(Fig. 1a, b)`. Use `X` literally if the user has not assigned numbers yet.
- For citations: `[citation needed]`, `[1]`, `[2]`, or numeric superscript placeholders. Group consecutive refs as `[1–3]`.
- For statistics the user did not provide: `[n = TBD]`, `[P = TBD]`.

NEVER silently omit figure/citation/stat anchors — Nature style requires them. Placeholders are honest; omission is fabrication risk.

## text vs text_compact differentiation

- `text`: full prose with all hedges, parenthetical asides, and calibrated redundancy.
- `text_compact`: ~60-70% length. Drops: parenthetical caveats, one of paired redundant clauses, redundant hedging. Keeps: lead claim, mechanism, anchor citations, all anti-AI fixes.

The two versions MUST differ measurably — at least 20% length difference or 2 substantive cuts. Never return them identical.

## Self-Check Precision (key vs other)

The word `key` is allowed in some Nature contexts (`key result`, `key step` of an experiment, `key parameter`). It is AI-tell ONLY when collocated with `key player`, `key regulator`, `key insight`, `key step toward` (decoration), `key role`. See `knowledge/anti_ai_patterns.tsv` for the precise regex. Do not over-flag.
